# MarshSaffron

MarshSaffron is a data visualization tool for geologists that analyzes borehole log data.

MarshSaffron is a Python tool that interprets and displays borehole log data in a clear format for geologists, facilitating data analysis and interpretation.

**Key benefits**

- Visualizes complex data in an easily understandable format
- Streamlines data analysis for geologists
- Improves data interpretation accuracy

## Key Features

- Imports CSV and JSON data files
- Supports multiple data formats
- Generates visualizations and reports

## Technology Stack

- Python

## Installation

1. Clone the repository using `git clone https://github.com/marshsaffron/marshsaffron.git`
2. Navigate to the project directory
3. Install dependencies using `pip install -r requirements.txt`

## Configuration

Configure the tool by editing the `config.json` file to specify data file paths and visualization settings
